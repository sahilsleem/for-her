# Photo Album Assets 📸 ♡

Drop your real couple photographs into this folder with these exact filenames:

1. **`couple-hero.jpg`** — Featured large photo at the top of the scrapbook (portrait or square works best)
2. **`couple-1.jpg`** — Quiet mornings / cozy times together
3. **`couple-2.jpg`** — Her unposed laugh / candid smile
4. **`couple-3.jpg`** — That little adventure / road trip / outdoor memory
5. **`couple-4.jpg`** — Being silly together / funny faces / photobooth
6. **`couple-5.jpg`** — A golden hour / evening date memory
7. **`couple-6.jpg`** — Holding hands / soft close-up memory

### How it works:
- If a file (e.g. `couple-1.jpg`) is present in this directory, the website will display your real photograph inside the polaroid frame.
- If a file is not yet added, the website automatically falls back to an illustrated romantic pastel placeholder so the layout never breaks or shows an ugly broken image!
- You can also add more photos by updating `js/data.js`.
