# Romantic Background Music 🎵 ♡

By default, the website includes a built-in soothing ambient music box & soft piano synthesizer powered by the browser's Web Audio API (meaning it works completely offline, with zero dependencies, and never fails to load!).

If you have a special song you both share:
1. Save your audio file here as **`our-song.mp3`**.
2. In `js/audio.js`, set `USE_CUSTOM_AUDIO = true`.
3. When she taps the floating music button, your special song will play in the background!
